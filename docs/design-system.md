# Дизайн-система NORO

Направление — «приборная панель»: графитовые поверхности, точная сетка, моноширинные детали, один фирменный сигнальный цвет и собственный акцент у каждого продукта. Тема одна — тёмная (`color-scheme: dark`), контраст проверен axe (WCAG 2.1 AA) на всех страницах.

Исходники: `src/design/tokens.css` (токены), `base.css` (сброс, типографика, фокус), `components.css` (компоненты), `site.css` (разделы сайта), `src/components/app/app.css` (рамка приложений).

## Цвет

| Токен | Значение | Назначение |
|---|---|---|
| `--bg`, `--bg-raise` | `#0a0b0c`, `#0f1112` | фон страницы |
| `--surface-1…4` | `#131517` → `#272b2f` | карточки, панели, поля, наведение |
| `--border`, `--border-strong` | `#2a2f33`, `#3a4045` | разделители |
| `--text`, `--text-2`, `--text-3` | `#eef0ee`, `#b4bab6`, `#8b928e` | основной, вторичный, приглушённый текст |
| `--signal` | `#c9f45f` | бренд NORO: главные действия, фокус |
| `--good` / `--warning` / `--critical` / `--info` | зелёный / янтарный / красный / голубой | только статусы, всегда с иконкой или подписью |
| `--series-1…8` | фиксированный порядок | категориальные цвета графиков |

Акценты продуктов задаются через `[data-product]` и переопределяют `--accent`: Lead Engine — оранжевый `#f08a4b`, Support — бирюзовый `#35c9a8`, Content OS — розовый `#ee7fb0`, Docs Intelligence — голубой `#6cb4ff`, Catalog Studio — жёлтый `#f2c14e`, Business Intelligence — сиреневый `#a597ff`.

## Типографика

- **Unbounded Variable** — заголовки H1/H2 (`--font-display`).
- **Onest Variable** — текст интерфейса (`--font-sans`).
- **JetBrains Mono** — числа, коды, файлы, подписи (`--font-mono`).

Шрифты локальные (fontsource), браузер загружает только нужные подмножества символов (`unicode-range`), `font-display: swap`. Размеры — шкала `--fs-xs … --fs-hero`; заголовки масштабируются `clamp()` так, чтобы самое длинное слово («автоматизировать») помещалось на экране 320 px.

## Пространство, форма, движение

- Отступы — шаг 4 px (`--sp-1 … --sp-24`), вертикальный ритм секций `--section-y`.
- Контейнер 1240 px, поля `--gutter` (16–40 px).
- Радиусы `--r-xs … --r-xl`, тени `--shadow-1…3`.
- Анимации `--dur-1…4` с `--ease-out`; при `prefers-reduced-motion: reduce` все длительности становятся 0 (проверяется e2e).
- Фокус — `--focus-ring` (двойное кольцо в цвете сигнала), виден на всех интерактивных элементах.

## Компоненты

| Компонент | Где | Варианты |
|---|---|---|
| Кнопка `.btn` | везде | `--primary`, `--signal`, `--outline`, `--ghost`, `--danger`; `--sm`, `--lg`, `--icon`, `--block` |
| Бейдж `.badge` | статусы, счётчики | `--good`, `--warning`, `--critical`, `--info`, `--accent`, `--outline` |
| Чип `.chip` | фильтры, переключатели | `aria-pressed` / `--active` |
| Метка возможности `.cap` | страницы продуктов | `--live` «Работает сейчас», `--connect` «Требует подключения», `--future` «Возможное расширение» |
| Уведомление `.alert` | ошибки и подсказки | `--good`, `--warning`, `--critical`, `--info` |
| Вкладки `Tabs` | приложения | WAI-ARIA tabs, стрелки/Home/End, тело приложения — `tabpanel` |
| Таблица `DataTable` | все продукты | сортировка, выбор строк, виртуализация больших наборов |
| `FileDrop`, `UploadButton` | импорт | перетаскивание, выбор файла, ограничения типов и размера |
| `MappingDialog` | импорт таблиц | сопоставление колонок с превью строк |
| `Modal`, `ConfirmDialog` | опасные действия | фокус внутри, Esc, подтверждение удаления |

| `AppFrame`, `StartPanel`, `StorageStatus` | рамка приложения | заголовок с источником данных, действия, статус хранения |
| `LineChart`, `BarList` | BI, Lead Engine | подсказки, легенда, перекрёстная фильтрация |

## Правила

- Статусные цвета не используются как цвета серий графиков и всегда дублируются текстом или иконкой.
- Пустые состояния объясняют, что делать дальше; ошибки говорят, что пошло не так и как исправить.
- Инлайн-стилей в HTML нет (этого требует CSP); динамические значения React задаёт через CSSOM.
- Сетка нигде не растягивается шире контейнера: колонки задаются как `minmax(0, 1fr)`; это проверяет аудит вёрстки на 320, 390, 768, 1024 и 1440 px.
