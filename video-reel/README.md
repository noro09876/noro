# Рекламный ролик «Ипотека 2%» — проект монтажа

Вертикальный ролик 1080×1920 / 30 fps / H.264 для Reels, TikTok, Shorts, собранный из селфи-видео клиента
в стиле референса: крупная типографика, b-roll-вставки, инфографика, титры «за спикером», музыка и SFX.

Проект сделан на [Remotion](https://remotion.dev) (React → видео) + Python/FFmpeg для подготовки материалов.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/Reel.tsx` | **Главный файл монтажа**: склейки (`T`), планы спикера (`CAMS`), все титры и графика по таймкодам |
| `src/config.ts` | Размер, длительность, шрифты, цвета, ник (`HANDLE`) |
| `src/components/Text.tsx` | `Headline` (крупные заголовки), `Light` (тонкие подписи), `Words` (слово-за-словом) |
| `src/components/Footage.tsx` | `Speaker` (видео клиента в 3 слоя: фон → титры → вырезанный спикер), `Broll` (фото-вставки) |
| `src/components/Graphics.tsx` | Плашки, календарь, линия срока, зачёркивание, график, «облачко» комментария |
| `scripts/prepare_client.py` | Апскейл 720→1080, цветокор, маска спикера → `public/client.mp4`, `public/fg/*.webp` |
| `scripts/prepare_broll.py` | Фото → вертикальные кадры `public/broll/*.jpg` (кадрировка задаётся в `CROPS`) |
| `scripts/make_audio.py` | Чистка голоса, музыка, SFX, мастеринг → `out/audio_master.wav` + стемы |
| `scripts/finish.sh` | Сведение картинки и звука → `out/final.mp4` |
| `scripts/build.sh` | Вся цепочка одной командой |
| `scripts/sheet.sh` | Проверочные раскадровки: `scripts/sheet.sh out/qa.jpg 100,250,770` |
| `assets/CREDITS.md` | Источники фото, шрифтов, лицензии |

## Как пересобрать

```bash
# исходное видео клиента положить в source/client.mp4 (в git не хранится)
npm i
pip install numpy scipy opencv-contrib-python-headless ai-edge-litert
bash scripts/build.sh          # всё целиком, результат: out/final.mp4
```

Правки только в титрах/графике не требуют шагов 1–3 — достаточно:

```bash
npx remotion studio            # живой предпросмотр с таймлайном
npx remotion render Reel out/reel_video.mp4 --codec=h264 --crf=13 --muted && bash scripts/finish.sh
```

## Частые правки

- **Текст титра / время появления** — `src/Reel.tsx`, блок «TYPE & GRAPHICS». `at`/`out` — кадры; `sec(12.5)` переводит секунды в кадры.
- **Точка склейки** — объект `T` в `src/Reel.tsx` (секунды речи). Если двигаете склейки, поправьте список `CUTS` в `scripts/make_audio.py`, чтобы свуши остались в синхроне.
- **Ник в Instagram** — `HANDLE` в `src/config.ts` (появится на финальной заставке).
- **Шрифт заголовков** — `FONT_HEAD` в `src/config.ts`. Для Montserrat: положить `assets/fonts/Montserrat-VF.ttf` в `public/fonts/`, добавить строку в `src/fonts.ts`, указать `FONT_HEAD = "Montserrat"`.
- **Заменить фото-вставку на свою съёмку** — положить файл 9:16 в `public/broll/` под тем же именем.
- **Свою музыку вместо синтезированной** — смикшировать `out/stems/voice.wav` + `sfx.wav` со своим треком.
- **Кодовое слово в призыве** — сейчас «2» (блоки 12–13 в `src/Reel.tsx`).
