# Motion DNA — моушн-стиль как данные

Формат и библиотека, в которых моушн-стиль рилса описан правилами и параметрами: **что** анимировать, **как** (приём + параметры), **когда** (речь, доля, онсет, дроп) и **чего не делать**. Сервис монтажа берёт стиль, свой таймлайн и сетку ритма и получает план анимации с абсолютными кадрами.

```
референс ──разбор (ANALYSIS.md)──▶ styles/*.json ─┐
музыка ──pipeline/analyze_audio.py──▶ beats.json ─┼─▶ pipeline/compile_plan.py ─▶ plan.json ─▶ любой рендерер
таймлайн агента (фразы, слова, отметки, клипы) ───┘                                         (здесь — Remotion)
```

## Что внутри

| Путь | Что это |
|---|---|
| `spec/motion-style.schema.json` | JSON Schema формата стиля: палитра, типографика по ролям, раскладка, ритм, вход/выход текста, акценты, плашки, переходы, камера, финиш, анти-шаблонные правила |
| `library/techniques.json` | Библиотека: 28 приёмов (вход и выход текста, акценты, плашки, переходы, камера, вспышки). У каждого: ключевые кадры, кривые, параметры с диапазонами, единица анимации, точка удара (`hit`), аудио-якорь, рейтинг узнаваемости `ai_tell` |
| `styles/editorial_mask.json`, `styles/punch_poster.json` | Два демо-стиля |
| `data/demo-timeline.json` | Пример входа от агента монтажа: фразы с таймингами слов, роли, отметки (ключевое слово, число), клипы |
| `pipeline/analyze_audio.py` | Звук → доли, сильные доли, онсеты по полосам, дроп/брейк (только numpy). Проверено на синтетическом треке с известной разметкой: средняя ошибка долей 7 мс, максимум 14 мс, дроп и брейк найдены |
| `pipeline/compile_plan.py` | Компилятор стиль + таймлайн + ритм → план (только стандартная библиотека Python). Валидирует стиль, детерминирован, логирует каждое решение с причиной |
| `pipeline/test_compile.py` | 8 проверок: детерминизм, запреты, `ai_tell`, диапазоны параметров, склейки на сетке, текст не переживает склейку, переносы |
| `src/` | Эталонный рендерер плана на Remotion: только интерпретирует ключи, своих решений не принимает |
| `renders/*.mp4` | Два ролика из одного таймлайна, отличается только файл стиля |
| `ANALYSIS.md` | Протокол разбора референса и шаблон «стиль за 7 строк» |

## Запуск

```bash
npm i
python3 -I pipeline/make_demo_audio.py public/music.wav data/music.truth.json     # демо-музыка (синтез)
python3 -I pipeline/analyze_audio.py public/music.wav data/beats.json data/music.truth.json
python3 -I pipeline/compile_plan.py styles/punch_poster.json data/demo-timeline.json \
        data/beats.json library/techniques.json src/plans/punch_poster.json
python3 -I -m unittest discover -s pipeline -p 'test_*.py'
npx remotion render punch-poster renders/punch-poster.mp4
```

Футаж — скриншоты сайта NORO (`pipeline/capture_broll.mjs`, нужен собранный и запущенный сайт из корня репозитория).

## Что важно для встраивания

- Стиль и библиотека — данные. Сервису достаточно их и своего рендерера; компилятор и рендерер здесь — эталонная реализация, её можно взять или переписать.
- План — плоский список слоёв с абсолютными кадрами и ключами `[t, value]` с кривыми Безье. Любой рендерер (Python + Skia/Pillow, ffmpeg-фильтры, Lottie, AE-скрипт) должен уметь только интерполировать ключи (`src/tracks.ts` — около 80 строк).
- Remotion бесплатен для команд до 3 человек; для компании нужна лицензия. Здесь он используется только для превью.
