# PhotoAgent

Локальная пакетная обработка фотографий по заданию на обычном русском языке. Всё работает на вашем компьютере: фотографии никуда не отправляются, платные сервисы не нужны.

Вы загружаете фото, папку или ZIP и пишете, что нужно сделать. Например: «Удали зелёный фон, аккуратно обработай волосы, помести в загруженный интерьер, согласуй освещение. Сохрани в исходном разрешении». Дальше PhotoAgent сам:

1. разбирает задание и показывает, что понял и чего не понял;
2. строит план обработки и проверяет, хватает ли моделей и референсов;
3. обрабатывает кадры по одному, проверяет каждый результат, при дефекте исправляет (не больше 2 повторов);
4. раскладывает результаты по папкам «готово» и «на проверку», пишет отчёт и собирает ZIP.

## Что умеет сейчас

| Операция | Как сделано | Что нужно |
|---|---|---|
| Удаление зелёного/синего фона | Цветоразностный ключ с учётом неровного света фона, расмешивание краёв, подавление ореола (despill) | ничего |
| Страховка маски и фон без хромакея | Нейросеть BiRefNet + уточнение краёв guided filter по самому фото | модель BiRefNet (кнопка «Скачать») |
| Замена фона / перенос в интерьер | Композитинг с подстройкой света по нейтральным тонам, light wrap, выравнивание зерна, контактная тень | фон в «Референсах» |
| Баланс белого, экспозиция, контраст, насыщенность | Классические алгоритмы в линейном цвете с ограничением силы | ничего |
| Цвет кожи, мелкие дефекты кожи | Поиск лиц YuNet, коррекция по «линии кожи», точечная ретушь с сохранением фактуры | модели лиц |
| Шумоподавление, резкость | Non-local means с оценкой уровня шума, адаптивная резкость | ничего |
| Увеличение разрешения | Нейросеть через ComfyUI (если есть), иначе Lanczos + резкость | по желанию: ComfyUI + RealESRGAN |
| Замена одежды | FLUX.2 klein 4B через локальный ComfyUI; лицо, причёска и кожа копируются из оригинала пиксель в пиксель | ComfyUI + модель FLUX.2 klein 4B |

Контроль качества после каждого кадра проверяет: открывается ли файл, размер и прозрачность, пустоту, дыры и «дымку» в маске, расхождение хромакея и нейросети, цветной ореол по контуру, согласованность света человека и фона, сходство лица с оригиналом (SFace), неизменность защищённых областей и появление «лишней» кожи после ИИ-редактирования (признак лишних рук или пальцев). Автоматика не гарантирует художественное качество, поэтому сомнительные кадры уходят «на проверку», а не в готовые.

## Установка на Windows

1. Установите Python 3.12 с https://www.python.org/downloads/ и отметьте «Add python.exe to PATH».
2. Скачайте папку `photoagent` из репозитория (или весь репозиторий) и запустите `install.bat`. Он создаст отдельное окружение `.venv` в этой папке, системный Python не изменится.
3. Запустите `run.bat`, и в браузере откроется http://127.0.0.1:8765.
4. В разделе «Модели и система» нажмите «Скачать» у BiRefNet Portrait, YuNet и SFace (около 1 ГБ).

Командная строка без интерфейса:

```bat
.venv\Scripts\python -m photoagent check                         :: проверка окружения
.venv\Scripts\python -m photoagent models download required      :: скачать основные модели
.venv\Scripts\python -m photoagent run D:\Фото\Класс "Удали зелёный фон, сохрани прозрачный PNG"
.venv\Scripts\python -m photoagent run D:\Фото\Класс "Удали зелёный фон и помести в интерьер" --background D:\фоны\зал.jpg
```

Данные хранятся в `photoagent_data` рядом с программой. Другую папку можно задать переменной окружения `PHOTOAGENT_DATA`. Для каждого задания создаётся своя папка:

```
photoagent_data/jobs/<id>/
  originals/   копии исходников, только для чтения
  refs/        референсы (фон, одежда…)
  work/        промежуточные результаты каждого шага и каждой попытки
  done/        готовые кадры (структура папок исходников сохраняется)
  review/      кадры, требующие проверки
  reports/     report.html и report.json
```

## Замена одежды и ИИ-увеличение (необязательно)

Для них нужен [ComfyUI](https://github.com/Comfy-Org/ComfyUI) (лицензия GPL-3.0, бесплатно) на этом же компьютере. PhotoAgent подключается к нему по адресу `http://127.0.0.1:8188`, другой адрес задаётся переменной `PHOTOAGENT_COMFYUI`. В ComfyUI нужны файлы:

- `models/diffusion_models/flux-2-klein-4b-fp8.safetensors` — FLUX.2 [klein] 4B, Apache 2.0;
- `models/text_encoders/qwen_3_4b.safetensors` — Apache 2.0;
- `models/vae/flux2-vae.safetensors` — Apache 2.0;
- по желанию `models/upscale_models/RealESRGAN_x4plus.pth` — BSD-3.

Раздел «Модели и система» показывает, чего не хватает. Без ComfyUI работают все остальные операции.

## Локальная языковая модель (необязательно)

Встроенный разбор заданий работает без нейросети. Если установлен [Ollama](https://ollama.com) и задана переменная `PHOTOAGENT_OLLAMA_MODEL` (например `qwen2.5:7b`), непонятые фразы можно доразобрать локальной моделью: для этого отметьте галочку в настройках экспорта. Модели передаётся только текст, без фотографий.

## Тесты

```bat
run_tests.bat
```

Проверяются чтение и запись без потерь (EXIF-поворот, 16 бит, прозрачность), хромакей на синтетических кадрах с известной маской, ореол, цветокоррекция, разбор заданий, план, контроль качества и полный путь от загрузки до ZIP, включая возобновление после перезапуска и работу через API.
