# Лицензии компонентов

Включено только то, что разрешает коммерческое использование без регистрации, оплаты и передачи фотографий.

## Используется

| Компонент | Назначение | Лицензия кода | Лицензия весов | Коммерция |
|---|---|---|---|---|
| OpenCV | классическая обработка | Apache 2.0 | — | да |
| Pillow, NumPy | чтение, запись, вычисления | MIT-CMU / BSD | — | да |
| FastAPI, Uvicorn | локальный веб-сервер | MIT / BSD | — | да |
| ONNX Runtime (+DirectML) | запуск нейросетей | MIT | — | да |
| BiRefNet (portrait, lite) | маска человека и волос | MIT | MIT | да |
| YuNet (OpenCV Zoo) | поиск лиц | MIT | MIT | да |
| SFace (OpenCV Zoo) | сравнение лица с оригиналом | Apache 2.0 | Apache 2.0 | да |
| ComfyUI (необязательно) | запуск тяжёлых моделей | GPL-3.0 | — | да, как отдельная программа; PhotoAgent обращается к нему по HTTP и не распространяет его код |
| FLUX.2 [klein] 4B (необязательно) | замена одежды | Apache 2.0 | Apache 2.0 | да |
| Qwen3-4B text encoder | текстовый кодировщик FLUX.2 klein | Apache 2.0 | Apache 2.0 | да |
| FLUX.2 VAE | кодировщик изображений FLUX.2 | Apache 2.0 | Apache 2.0 | да (перед скачиванием сверить карточку модели) |
| Real-ESRGAN x4plus (необязательно) | ИИ-увеличение | BSD-3 | BSD-3 | да |
| Ollama + Qwen2.5 (необязательно) | разбор сложных формулировок | MIT / Apache 2.0 | Apache 2.0 (7B) | да |

Веса BiRefNet скачиваются из релизов проекта rembg (MIT): там лежат ONNX-копии официальных весов BiRefNet. Каждый файл проверяется по SHA-256 (суммы в `photoagent/models.py`).

## Отклонено

| Компонент | Причина |
|---|---|
| RMBG-2.0 (BRIA) | CC BY-NC 4.0: для коммерции нужна платная лицензия |
| FLUX.2 [klein] 9B, FLUX.1 [dev], FLUX.1 Kontext [dev] | FLUX Non-Commercial License |
| InsightFace (antelopev2, buffalo_l), InstantID, PuLID на их основе | веса только для некоммерческого использования |
| OpenPose (CMU) | некоммерческая лицензия |
| Плагины Adobe, Creative Claw и подобные облачные сервисы | фотографии уходят во внешний сервис |
| Платные API генерации | противоречат требованию бесплатной локальной работы |
