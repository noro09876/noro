# Интеграции: площадки и ИИ-провайдеры

Фабрика публикует только через официальные API и официальную авторизацию (токен бота или OAuth).
Пароли от соцсетей не запрашиваются и не хранятся, имитации браузера нет. Там, где официального
API публикации нет, фабрика готовит пакет для ручного размещения, а пост считается размещённым
только после того, как человек вставит ссылку на него.

Все токены хранятся в базе зашифрованными (AES-256-GCM, ключ из `MASTER_KEY`), в ответы API
и в журнал не попадают. Публикация идемпотентна: ключ строится из материала, версии, площадки
и аккаунта. Подтверждённый пост повторно не отправляется. Если отправка прервалась на середине,
пост получает статус «результат неизвестен» и не повторяется автоматически: человек проверяет
площадку и подтверждает повтор.

`{PUBLIC_URL}` ниже означает значение переменной `PUBLIC_URL`, например `https://factory.example.com`.

## Сводная таблица

| Площадка | Способ | Что публикуется через API | Нужна проверка площадки | Статистика |
|---|---|---|---|---|
| Telegram | Токен бота | текст, фото, карусель (альбом), видео до 50 МБ | нет | только подписчики (Bot API не отдаёт просмотры) |
| ВКонтакте | OAuth VK ID | текст, фото, карусель, видео | нет (нужен подтверждённый домен приложения) | лайки, репосты, просмотры, охват |
| MAX | Токен бота | текст, фото, видео | бота создаёт только верифицированное юрлицо РФ | нет |
| Instagram | OAuth (Instagram Login) | фото JPEG, карусель, Reels; без текстовых постов | App Review Meta; до него только тестировщики | охват и просмотры (нужен scope insights) |
| Threads | OAuth | текст до 500 символов, фото, карусель, видео | App Review Meta; до него только тестировщики | просмотры, лайки, ответы |
| YouTube Shorts | OAuth Google | вертикальное видео до 3 минут | верификация приложения Google для внешних пользователей | просмотры, лайки, комментарии |
| TikTok | OAuth (Content Posting API) | видео | аудит TikTok; до него только приватно (SELF_ONLY) | недоступно без отдельного scope |
| Дзен | вручную | пакет: заголовок, текст, обложка 16:9 | публичного API нет | нет |
| Teletype | вручную | пакет: заголовок, текст, изображения | публичного API нет | нет |
| VC.ru | вручную | пакет: заголовок, текст, изображения | документированного API нет | нет |

Instagram, Threads и TikTok скачивают медиа по ссылке сами, поэтому для них `PUBLIC_URL`
должен быть доступным из интернета HTTPS-адресом (или используйте S3-хранилище с публичным
`S3_PUBLIC_BASE_URL`).

## Площадки: как подключить

### Telegram
1. Откройте @BotFather, отправьте `/newbot`, сохраните токен.
2. Добавьте бота в канал администратором с правом «Публикация сообщений».
3. В фабрике: «Аккаунты → Telegram → Подключить», вставьте токен и `@username` канала
   (или числовой ID приватного канала, начинается с `-100`).
4. Фабрика проверит права бота (`getMe`, `getChat`, `getChatMember`) и сохранит подключение.
5. Для пробных публикаций заведите отдельный приватный канал и отметьте подключение как тестовое:
   такие публикации помечаются «тест».

Ограничения: подпись к медиа до 1024 символов (длинный текст уходит отдельным сообщением),
файлы до 50 МБ, отложенной публикации в Bot API нет (время соблюдает планировщик фабрики).

### ВКонтакте
1. Создайте приложение типа «Веб» в кабинете VK ID: https://id.vk.com/about/business/go
2. Добавьте доверенный Redirect URL `{PUBLIC_URL}/api/oauth/callback/vk` и базовый домен.
3. Скопируйте ID приложения и защищённый ключ в «Аккаунты → ВКонтакте → Настроить приложение».
4. Нажмите «Подключить», войдите администратором сообщества и выберите сообщество.

Права: `wall, photos, video, groups, offline`. Ключ обновляется refresh-токеном автоматически.
Лимит стены: 50 записей в сутки.

### MAX
1. Зарегистрируйте организацию на https://business.max.ru и пройдите верификацию
   (с августа 2025 ботов создают только юрлица РФ).
2. Создайте бота, скопируйте токен, добавьте бота администратором в канал.
3. В фабрике вставьте токен и ID канала.

### Instagram
1. Переведите аккаунт в профессиональный (бизнес или автор).
2. В Meta for Developers создайте приложение типа Business и добавьте продукт
   «Instagram API with Instagram Login».
3. Redirect URL: `{PUBLIC_URL}/api/oauth/callback/instagram` (HTTPS).
4. До App Review добавьте свой аккаунт в роли Instagram Tester. Для работы с аккаунтами
   клиентов пройдите App Review с `instagram_business_basic` и `instagram_business_content_publish`.
5. Вставьте App ID и App Secret в фабрике и нажмите «Подключить».

Ограничения: только JPEG, текстовых постов нет, 100 публикаций через API за 24 часа.

### Threads
1. В Meta for Developers создайте приложение с продуктом «Threads API».
2. Redirect URL: `{PUBLIC_URL}/api/oauth/callback/threads` (HTTPS).
3. До App Review добавьте свой профиль в тестировщики и примите приглашение в настройках Threads.
4. Вставьте App ID и App Secret и подключите профиль.

### YouTube Shorts
1. В Google Cloud Console создайте проект и включите YouTube Data API v3.
2. Настройте экран согласия OAuth (External) и добавьте себя в тестовые пользователи.
   Для клиентов пройдите верификацию приложения Google.
3. Создайте OAuth Client ID типа «Web application» с Redirect URI
   `{PUBLIC_URL}/api/oauth/callback/youtube`.
4. Вставьте Client ID и Secret и подключите канал.

Квота загрузок по умолчанию 100 видео в сутки на проект. Публикацию можно сделать приватной
(тестовой): такие посты помечаются «видно только автору».

### TikTok
1. Создайте приложение (Web) на https://developers.tiktok.com.
2. Добавьте Login Kit и Content Posting API, включите Direct Post и scope `video.publish`.
3. Redirect URI: `{PUBLIC_URL}/api/oauth/callback/tiktok`.
4. До аудита TikTok публикация возможна только в приватном режиме (SELF_ONLY) и только
   с приватных аккаунтов. Фабрика честно помечает такие посты как видимые только автору.
   Для публичных постов подайте приложение на аудит.
5. Вставьте Client key и Client secret и подключите аккаунт.

### Дзен, Teletype, VC.ru
Официального API публикации нет, поэтому фабрика не публикует туда автоматически и не
использует неофициальные способы. На карточке публикации есть «Пакет для ручной публикации»
(ZIP с текстом, заголовком и изображениями). После размещения вставьте ссылку на материал:
фабрика проверит, что ссылка ведёт на нужный домен (`dzen.ru`, `teletype.in`, `vc.ru`),
и только тогда отметит «Размещено вручную».

## ИИ-провайдеры

Подписка на чат-интерфейс (Claude Pro, ChatGPT Plus) не даёт доступа к API. Для генерации
нужен отдельный API-ключ с оплатой по использованию. Ключи вводятся в «Настройки → Провайдеры ИИ»,
шифруются и проверяются запросом к API провайдера.

| Назначение | Провайдер | Что нужно |
|---|---|---|
| Тексты, стратегия | Anthropic Claude | ключ из Claude Console (platform.claude.com → API Keys) |
| Тексты, стратегия | OpenAI | ключ с platform.openai.com |
| Тексты, стратегия | YandexGPT | сервисный аккаунт с ролью `ai.languageModels.user`, API-ключ и ID каталога |
| Тексты, стратегия | OpenAI-совместимый (Ollama, LM Studio, OpenRouter, vLLM) | базовый URL и при необходимости ключ |
| Фоны для графики | OpenAI Images | ключ OpenAI; для gpt-image нужна верификация организации |
| Озвучка | Piper (локально, бесплатно) | `npm run tts:setup`, ключ не нужен |
| Озвучка | OpenAI TTS | ключ OpenAI |
| Озвучка | ElevenLabs | ключ и Voice ID |

Без ключа LLM фабрика не выдумывает контент: стратегия завершается понятной ошибкой,
а материалы можно писать вручную во встроенных редакторах. Карусели, графика и видео
рендерятся шаблонами Remotion без внешних сервисов. Для автотестов и демонстрации есть
«Тестовый провайдер (не ИИ)», его тексты помечены «[ТЕСТ]», а в продакшене он выключен.

Лимиты пространства (генерации и рендеры в сутки, материалов в кампании) настраиваются
в «Настройки → Лимиты» и защищают от случайного массового расхода.
