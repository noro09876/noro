# NORO AI Content Factory

Контент-фабрика для брендов: от брифа до опубликованного поста. Строит стратегию и контент-план,
пишет посты, собирает карусели и графику в фирменном стиле, превращает сценарии в вертикальные
видео с озвучкой и субтитрами, адаптирует всё под площадки, проверяет, отправляет на согласование,
планирует и публикует через официальные API, собирает статистику и ведёт журнал операций.

Модули: Обзор, Brand Studio, AI Content Studio (кампании и материалы), Motion Studio, Календарь,
Аккаунты, Автоматизация, Аналитика, Журнал операций, Настройки, Витрина возможностей.

Площадки: Telegram, ВКонтакте, MAX, Instagram, Threads, YouTube Shorts, TikTok — через API;
Дзен, Teletype, VC.ru — пакет для ручного размещения (официального API публикации нет).
Подробности и шаги подключения — [docs/integrations.md](docs/integrations.md).
Устройство системы — [docs/architecture.md](docs/architecture.md).

## Быстрый старт (Docker)

```bash
cp .env.example .env
# задайте MASTER_KEY и SESSION_SECRET (openssl rand -base64 48) и PUBLIC_URL
docker compose up -d --build
open http://localhost:8787
```

Первый зарегистрированный пользователь получает своё пространство. Дальше: «Настройки →
Провайдеры ИИ» (ключ LLM), «Brand Studio», «Аккаунты», «Кампании → Новая кампания».

## Локальная разработка

Нужны Node.js 22+, PostgreSQL 15+, ffmpeg, Python 3 (для локальной озвучки Piper).

```bash
npm install
createdb noro_factory            # или задайте DATABASE_URL
npm run tts:setup                # бесплатная локальная озвучка Piper (русский голос)
npm run dev                      # API + воркер на :8787, интерфейс Vite на :5173
```

Продакшен без Docker: `npm run build && npm start` (API и воркер в одном процессе)
или `INLINE_WORKER=0 npm start` плюс `npm run start:worker`.

## Демо-витрина

```bash
npm run showcase:build
```

Создаёт изолированное демо-пространство «Демо: Veltro» с вымышленным брендом: стратегия,
5 постов, 2 карусели, 3 графики, 2 сценария и 2 отрендеренных вертикальных видео с озвучкой
Piper и субтитрами, версии для площадок, календарь, примеры проверок и согласований.
Тексты витрины подготовлены заранее и помечены как демо (не выдаются за ответ модели),
визуалы и видео рендерит сама фабрика. Демо-публикации никуда не отправляются.
Пространство доступно всем пользователям только для чтения: раздел «Витрина возможностей».

## Проверки

```bash
npm run typecheck
npm run lint
npm test                 # unit + интеграционные (нужна TEST_DATABASE_URL)
npm run build
npm run test:e2e         # Playwright, десктоп и мобильный (нужна база noro_factory_e2e)
```

Интеграционные тесты поднимают фейковый Telegram Bot API и проверяют: успешную публикацию,
отсутствие дублей при повторных задачах, экспоненциальные повторы, Retry-After, отзыв токена,
«результат неизвестен», конфликты расписания, ручные площадки, роли, CSRF и то, что токены не
попадают в ответы API, базу и журнал в открытом виде.

## Честные ограничения

- Без API-ключа языковой модели стратегия и тексты не генерируются: фабрика показывает ошибку,
  а материалы можно написать вручную. Тестовый провайдер есть только для тестов и помечен «ТЕСТ».
- Статус «Опубликовано» ставится только после подтверждения площадки (ID и ссылка поста).
  Тестовые и приватные публикации помечаются отдельно.
- Метрики показываются только те, что отдаёт API площадки; остальное подписано как недоступное.
- Instagram, Threads и TikTok требуют проверки приложения площадкой для работы с чужими
  аккаунтами; до неё публикация возможна только для тестировщиков (TikTok — только приватно).
