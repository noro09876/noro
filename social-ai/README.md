# NORO Social AI

Автономная система создания и публикации контента для соцсетей. Агент составляет контент-план, пишет посты, статьи и карусели локальной языковой моделью (Ollama), рисует слайды в едином стиле, проверяет материал и публикует его по расписанию через официальные API Telegram, ВКонтакте, Instagram и X. Всё работает на вашем компьютере, бесплатно, без внешних ИИ-сервисов.

## Что нужно

- Node.js 22.18 или новее (проверено на 22.22).
- Ollama с любой моделью для русского текста — для автоматической генерации. Без модели NORO работает как планировщик и редактор: материалы можно писать вручную.
- Около 300 МБ на диске для приложения; модель Ollama 7–8B занимает ещё ~5 ГБ.

## Запуск

```bash
cd social-ai
npm ci
npm run build      # собрать интерфейс
npm start          # http://127.0.0.1:8787
```

Откройте http://127.0.0.1:8787 и создайте администратора (логин и пароль от 10 символов). Если открываете NORO не с того компьютера, где он запущен, понадобится код первичной настройки — он печатается в консоли сервера.

Режим разработки (сервер с перезапуском + Vite на :5173): `npm run dev`.

Docker: `docker compose up -d` (NORO) или `docker compose --profile ollama up -d` (NORO + Ollama в контейнере). Данные лежат в `./data`.

## Первая настройка (10 минут)

1. **Модель.** Установите Ollama (ollama.com), затем `ollama pull qwen2.5:7b` (или другую модель). В NORO: «Настройки → Модели» → «Проверить сервер и список моделей» → выберите модель → «Сохранить» → «Тестовый запрос».
2. **Бренд.** «Настройки → Бренд»: подпись на слайдах (@ник), акцентный цвет, аудитория, голос, запрещённые слова.
3. **Аккаунты.** «Аккаунты» → «Подключить» у нужной площадки (инструкции ниже). NORO сразу проверит доступ и покажет реальную причину, если что-то не так.
4. **Агент.** «ИИ-агент»: выберите тематики, количество публикаций в день и время, форматы, площадки, тон. Нажмите «Дополнить план», затем «Запустить цикл сейчас» и посмотрите результат в «Контенте».
5. Когда качество устраивает — включите «Публиковать без моего подтверждения» и переключатель «Агент работает автоматически». Дальше агент сам планирует, пишет, проверяет и публикует; ваше участие не требуется.

## Подключение соцсетей

Пароли от соцсетей NORO не запрашивает. Используются только официальные токены API; они шифруются (AES-256-GCM) и не возвращаются в браузер.

### Telegram — бесплатно, работает полностью
1. Напишите @BotFather → `/newbot` → скопируйте токен.
2. Добавьте бота в канал администратором с правом «Публикация сообщений».
3. В NORO: токен бота и `@username` канала (или числовой ID вида `-100…`).

Карусель уходит альбомом (до 10 изображений). Если текст длиннее 1024 символов, подпись к альбому — заголовок, а полный текст идёт следующими сообщениями. Статистику постов канала Bot API не отдаёт — в аналитике будет «—».

### ВКонтакте — бесплатно
1. Вы должны быть администратором или редактором сообщества.
2. id.vk.com → «Мои приложения» → создайте приложение, включите доступы `wall`, `photos`, `groups`, `offline`.
3. Получите **пользовательский** ключ доступа авторизацией через VK ID этого приложения. Ключ сообщества не подойдёт: ВКонтакте не разрешает им постить на стену (NORO скажет об этом прямо).
4. В NORO: ключ и числовой ID сообщества.

Публикация идёт с параметром `guid`, поэтому повтор после обрыва связи не создаёт дубль. Лимит ВКонтакте — 50 постов в сутки. Статистика (просмотры, лайки, репосты, комментарии) собирается автоматически.

### Instagram — API бесплатный, но есть условия
- Аккаунт должен быть профессиональным (Business или Creator).
- Приложение на developers.facebook.com с продуктом «Instagram API with Instagram Login», разрешения `instagram_business_basic`, `instagram_business_content_publish`. До проверки приложения Meta публиковать можно только в аккаунты, добавленные в роли приложения.
- Долгоживущий токен (60 дней) — вставьте в NORO и обновляйте до истечения.
- **Instagram скачивает картинки сам по публичной ссылке**, поэтому NORO должен быть доступен из интернета по HTTPS. Бесплатный вариант — Cloudflare Tunnel: `cloudflared tunnel --url http://127.0.0.1:8787`, полученный адрес укажите в `NORO_PUBLIC_URL` в `.env` и перезапустите NORO. Ссылки на картинки подписаны и не угадываются.
- Лимит Meta — до 100 публикаций через API за 24 часа, только JPEG, до 10 изображений в карусели.

### X (Twitter) — платно
С 2026 года X API работает по модели pay-per-use, бесплатного уровня для новых проектов нет. NORO поддерживает подключение (OAuth 2.0 с PKCE) и публикацию, но без пополненного баланса X вернёт ошибку оплаты — NORO покажет её как есть и не будет повторять. Шаги: проект на developer.x.com, OAuth 2.0 с правами Read and write, Callback URL `http://127.0.0.1:8787/api/oauth/x/callback`, Client ID (и Secret) в NORO, затем «Авторизоваться в X». Сбор статистики X выключен по умолчанию — чтения тоже платные.

## Как работает агент

Каждые ~20 секунд планировщик:
1. Публикует то, у чего подошло время, и повторяет временно неудачные попытки с растущими паузами (1, 5, 15, 60 мин…, не больше заданного числа попыток).
2. Раз в минуту запускает цикл агента: дополняет контент-план на N дней (тематики и форматы чередуются, учитываются прошлые заголовки и лучшие по статистике материалы), за `leadHours` до слота пишет материал, рисует слайды, проверяет и — если включено автоодобрение — ставит в расписание.
3. Раз в 6 часов проверяет доступность аккаунтов и собирает статистику; раз в сутки делает резервную копию.

Проверка перед публикацией останавливает пост, если: пустой текст, заглушки (`TODO`, `[вставьте…]`), смешение латиницы и кириллицы в словах, обещания гарантированного дохода, запрещённые слова бренда, текст не помещается на слайд, не тот формат/размер/пропорции изображения, превышены лимиты площадки или аккаунта, материал уже публиковался (точный или почти дословный повтор), нет прав, не задан публичный адрес для Instagram. Причина видна в карточке материала, в календаре и в журнале.

Предохранители: не больше заданного числа генераций в сутки; не больше N попыток на слот; одна автоматическая доработка по замечаниям проверки; пауза агента после серии ошибок подряд (возобновляется кнопкой); заготовки без модели никогда не публикуются автоматически.

Если соединение оборвалось в момент публикации (пост мог выйти), NORO не повторяет его вслепую: публикация получает статус «Нужна проверка», и вы отмечаете «Пост вышел» или «Не вышел». То же после аварийного перезапуска.

## Безопасность

- Сервер по умолчанию слушает только `127.0.0.1`.
- Пароль — scrypt; блокировка на 15 минут после 5 неудачных попыток; cookie HttpOnly + CSRF-токен.
- Токены — AES-256-GCM. Ключ — `data/master.key` (права 600) или `NORO_MASTER_KEY`. В резервные копии ключ не входит.
- Журнал и тексты ошибок очищаются от токенов до записи.

## Резервные копии

Ежедневно в заданный час (`data/backups`, хранится 14 копий), вручную — «Настройки → Резервные копии» или `npm run backup`. Восстановление (сервер остановлен): `npm run restore -- noro-YYYY-MM-DDTHH-MM-SS.db`. Сброс пароля: `npm run reset-password`.

## Новые тематики, бренды и площадки

- Тематики добавляются в «ИИ-агент» без перезапуска; бренд — в настройках.
- Новая площадка = модуль в `server/integrations/` с методами `check`, `publish`, `metrics` + строка в `server/integrations/index.ts` и правила в `server/platforms.ts`.
- Новый поставщик моделей — в `server/ai/llm.ts` (сейчас Ollama и любой OpenAI-совместимый сервер: LM Studio, llama.cpp, vLLM).

## Проверки

```bash
npm run typecheck   # TypeScript: сервер и интерфейс
npm test            # 55 тестов: модули, интеграции на имитаторах API, агент, перезапуск, HTTP API
npm run test:e2e    # Playwright: полный сценарий в браузере + мобильная вёрстка
```

## Структура

```
server/
  index.ts, app.ts       запуск, сборка сервисов, безопасность HTTP
  db.ts                  SQLite (встроенный node:sqlite) и миграции
  crypto.ts, log.ts      шифрование, пароли, журнал с маскировкой секретов
  settings.ts, time.ts   настройки (zod), часовые пояса
  content.ts             материалы, хеши, рендер изображений
  carousel/              раскладка текста по метрикам шрифта и рендер слайдов (resvg → JPEG)
  validate.ts, platforms.ts  проверка перед публикацией, правила и тексты для площадок
  integrations/          telegram, vk, instagram, x — по модулю на площадку
  publisher.ts           расписание, публикация, повторы, защита от дублей, восстановление
  agent.ts, ai/          план, генерация, промпты, клиенты моделей
  scheduler.ts, backup.ts, cli.ts
  routes/                HTTP API и авторизация
  assets/fonts/          Inter (OFL) для слайдов
web/src/                 интерфейс (React): страницы, компоненты, стили
tests/                   автотесты и имитаторы API площадок и Ollama
e2e/                     браузерные сценарии Playwright
```
