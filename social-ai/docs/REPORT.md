## 2. Архитектура и почему такая

- **Сервер:** Node.js 22 + Fastify 5, TypeScript запускается напрямую (без шага сборки).
- **База:** встроенный SQLite (`node:sqlite`), режим WAL. Ни Postgres, ни Redis не нужны: один процесс, всё состояние (расписание, план, блокировки публикаций) в одном файле — переживает перезапуск.
- **Планировщик:** внутри процесса, такт 20 с, все задачи берутся из БД.
- **ИИ:** Ollama (структурированный JSON-вывод по схеме) или любой OpenAI-совместимый локальный сервер. Внешние адреса заблокированы, пока вы явно не разрешите (могут быть платными).
- **Карусели:** собственный рендер: раскладка текста по реальным метрикам шрифта (opentype.js), SVG-шаблон, растеризация resvg → JPEG. Без браузера, без платных API, одинаковый результат на любой машине.
- **Интерфейс:** React 19 + Vite, токены дизайн-системы NORO из портфолио.

## 3. Реализованные функции

**Интерфейс (8 разделов):** Главная, Аккаунты, Контент (список и редактор с покадровым просмотром слайдов), Календарь (день/неделя/месяц, перенос перетаскиванием и изменение времени), ИИ-агент, Аналитика, Журнал, Настройки (модели, изображения, расписание и лимиты, бренд, резервные копии, безопасность). Адаптивная вёрстка проверена на 375 px.

**Агент:** контент-план на N дней с чередованием тематик и форматов; идеи от модели с учётом прошлых заголовков и лучших материалов по статистике; генерация заголовка, текста, описания, CTA, хештегов, слайдов; одна автоматическая доработка по замечаниям проверки; автоодобрение и постановка в расписание; запрет выдумывать цифры и исследования в системном промпте плюс предупреждение в проверке, если цифры всё же появились.

**Карусели:** обложка, слайды «одна мысль», финальный слайд; счётчик, подпись бренда, акцентный цвет; подбор кегля под объём текста; ошибка при переполнении; неразрывные пробелы после предлогов; 1080×1350 или 1080×1080; экспорт ZIP.

**Проверка перед публикацией:** пустой текст, заглушки, смешение алфавитов, повторы слов, парность кавычек и скобок, капслок, гарантии дохода, запрещённые слова, формат/размер/пропорции изображений, лимиты текста площадки, лимит публикаций аккаунта в день, точные и почти дословные повторы, права аккаунта, публичный адрес для Instagram.

**Публикация и контроль:** ID и ссылка поста, повторы при 429/5xx/сетевых сбоях с растущими паузами и лимитом попыток, немедленная остановка при ошибках авторизации/прав/оплаты с пометкой аккаунта, статус «Нужна проверка» при обрыве в момент публикации (никаких слепых повторов), восстановление после аварийного перезапуска, уникальность пары «материал — аккаунт».

**Надёжность и безопасность:** вход администратора (scrypt, блокировка, CSRF), шифрование токенов AES-256-GCM, маскировка секретов в журнале и в текстах ошибок, подписанные ссылки на изображения, ежедневные резервные копии, лимит генераций в сутки, пауза агента после серии ошибок.

Ошибок в консоли браузера нет.
- Ручная проверка процесса: сервер остановлен сигналом и запущен снова — включённый агент, план и расписание сохранились, цикл продолжился.

Найдено и исправлено тестами: токен бота попадал в текст ошибки аккаунта (теперь маскируется), регулярное выражение не находило смешение алфавитов в кириллице, статические файлы новой сборки не отдавались без перезапуска, горизонтальная прокрутка на телефоне в журнале.

## 7. Что осталось и ограничения

- Реальная генерация на Ollama не проверялась (модель недоступна в облаке). Качество текстов зависит от выбранной модели; модели 7–8B иногда нарушают ограничения длины — проверка это ловит и просит доработку, но стоит начать с ручного подтверждения.
- Проверка текста эвристическая: она ловит дефекты генерации, но не заменяет корректора. Подключение LanguageTool (можно локально, бесплатно) — возможное расширение.
- Токен Instagram живёт 60 дней — автоматического продления пока нет, NORO покажет «Нужна авторизация».
- Для ВКонтакте нужно вручную получить пользовательский ключ через VK ID; встроенного OAuth-входа ВК пока нет.
- Docker-образ написан, но не собран (демон Docker недоступен в окружении).
- Telegram не отдаёт статистику постов через Bot API — это ограничение площадки.
- Изображения не входят в резервную копию БД — их можно пересобрать из текста кнопкой «Пересобрать».
- Круглосуточная работа требует включённого компьютера или сервера. Бесплатные хостинги обычно усыпляют процесс или ограничивают диск — гарантировать бесплатную круглосуточную работу на удалённом сервере нельзя.
